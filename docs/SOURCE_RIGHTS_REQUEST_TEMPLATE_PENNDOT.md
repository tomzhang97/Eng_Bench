# PennDOT Redistribution Permission Request

Send to: `RA-PDBridgePubs@pa.gov`

Subject: Permission request for PennDOT bridge-standard excerpts in Eng_Bench

## Email Draft

Hello PennDOT Bridge Publications team,

We are preparing Eng_Bench, a research benchmark for evaluating machine
learning systems on engineering drawings and technical documents. We would
like written permission to include rendered page images and small cropped text
regions derived from PennDOT bridge-standard publications, including the
BD-600M, BC-700M, and related archived 2016 bridge-standard index/revision
materials available from the PennDOT bridge standards pages.

The public benchmark would redistribute the images together with questions and
ground-truth text labels. It may be used by academic and commercial research
groups to evaluate document-understanding systems. We would retain PennDOT
attribution and source URLs and would not imply PennDOT endorsement.

Could you please confirm:

1. Whether PennDOT permits redistribution of these rendered pages and cropped
   regions in a public machine-learning benchmark.
2. Whether commercial research use is permitted.
3. The required attribution wording.
4. Any license, notice, or restrictions that must accompany the files.
5. Whether permission covers archived as well as current bridge standards.

If blanket permission is not available, please let us know whether a specific
written license or another approval process is required.

Thank you.
